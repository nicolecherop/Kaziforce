# CV import verification — 12 November 2026

The final PostgreSQL regression run passed **427 tests** in 73.399 seconds,
including **35 new CV import tests**. The separate test database was used;
live candidate profiles, documents, accounts and application snapshots were
not modified. CV fixtures use fictional details and reserved email addresses.
The test-process-only two-step override follows the existing regression setup;
security-specific tests enable their required settings. External email and
payment calls are isolated or mocked, not sent.

Covered:

- Reading text-based PDF and DOCX, including Word table/header paragraphs.
- Structured contacts, summary, explicit skills, education, certificates,
  professional links and dated employment; multiple jobs and alternative headers.
- Month-only date disclosure, year-only dates left blank, editable review.
- Scanned/empty PDFs, encrypted PDFs, excessive pages, malformed documents,
  unsafe XML entities, macros, expanded ZIP sizes and worker timeouts.
- Optional upload-to-review flow, existing-file import and attachment retention.
- No profile writes on preview/discard; explicit selection and correction.
- Preservation of existing fields and entries, duplicate elimination, limits,
  stale-review rejection, single-use save and atomic rollback.
- Candidate ownership, recruiter rejection, CSRF, POST-only actions,
  expired/deleted-file reviews, request throttling and escaped source text.

`manage.py check`, `makemigrations --check --dry-run`, `pip check` and
`git diff --check` passed. No schema migration is needed. The running site's
home page returned HTTP 200 at http://127.0.0.1:8001/.

Browser automation could not connect to its host, so visual browser inspection
was not completed. Template rendering and upload/review/save HTTP routes were
checked by the automated tests. Participant acceptance and field-by-field
accuracy checks on varied, consented real CVs remain pending. These fixture
results are not a measured extraction accuracy percentage.
