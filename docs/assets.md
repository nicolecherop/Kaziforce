# Public page assets

## Video and poster

`static/video/talent-matching.mp4` is a silent 1080p H.264 web copy of the supplied `8643643-uhd_3840_2160_24fps.mp4`. `static/images/hero-poster.jpg` is a frame from that video, used only within the hero as its fallback. The video autoplays and loops without on-page playback controls. Reduced-motion and data-saving preferences show the still instead. The scroll prompt has been removed.
