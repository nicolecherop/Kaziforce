# ESCO English skill reference

Public ESCO content is provided by the European Commission. KaziForce retains an English CSV export of released skill concepts from the official API, pinned to v1.2.0. The adjacent JSON manifest records the query, source URL, retrieval date, unique skill count and CSV SHA-256 checksum. Preferred/alternative labels and descriptions are ESCO content; this project does not claim authorship of them.

The prepared catalogue contains 13,939 individual skills and knowledge concepts. It excludes 640 classification groups returned alongside them by the bulk API; the manifest retains the classification-filter provenance.

Source: https://ec.europa.eu/esco/api/resource/skill

Documentation: https://esco.ec.europa.eu/en/use-esco/use-esco-services-api/esco-web-service-api

Alternative official CSV distribution: https://esco.ec.europa.eu/en/use-esco/download

This directory contains public reference data only. See ../../docs/skill-standardization.md for import and validation details.
